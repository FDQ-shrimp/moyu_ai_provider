# 魔芋AI 0.0.6 双站模型验证报告

> 验证日期：2026-09-17<br>
> 国内站：`https://www.moyu.cn/v1`<br>
> 海外站：`https://www.konjac.ai/v1`

本报告是发布 `0.0.6` 时的可用性快照。上游模型状态、账户权限和限流策略
可能随时间变化；插件运行时实际结果始终以上游服务当时的响应为准。

## 目录与验证结果

| 项目 | 数量 |
|---|---:|
| 国内站 `/models` 返回 | 163 |
| 海外站 `/models` 返回 | 68 |
| 两站同名交集 | 59 |
| 双站实测成功的 LLM/兼容聊天模型 | 48 |
| 双站实测成功的 Embedding | 2 |
| 额外注册的仅国内站 LLM | 10 |
| 额外注册的仅国内站 Embedding | 2 |
| 插件最终注册总数 | 62 |

最终注册目录由 `provider/moyu.yaml` 的显式白名单决定：

- 58 个 LLM：48 个双站模型＋10 个仅国内站模型；
- 4 个 Embedding：2 个双站模型＋2 个仅国内站模型；
- 所有仅国内站模型均带中英文站点标签；
- Rerank 当前不注册。

## 双站共同目录中的排除项

下列模型虽然同时出现在两站 `/models` 目录，但不适合当前插件的
LLM/Embedding 调用方式，因此未注册：

- `gemini-3-pro-preview`
- `gpt-image-2`
- `qwen-image-3.0`
- `veo-3`
- `veo-3-fast`
- `veo-3.1`
- `veo-3.1-fast`
- `wan2.6-image`
- `wan2.7-image`

这些条目主要属于不可用预览模型或需要其他图像、视频协议的模型，不能仅凭
出现在 `/models` 中就视为可通过 `/chat/completions` 正常调用。

## Rerank

`qwen3-rerank` 在国内站与海外站验证时均返回 `model_not_found`，因此
`0.0.6` 同时关闭 manifest 权限、provider 类型声明和模型注册。旧适配器代码
仅作为历史参考保留，不会被 Dify 运行时加载。

## 国内站补充模型

为照顾国内用户，插件在双站共同目录之外增加了已验证的国内站模型。
`DeepSeek-V3.1` 因返回模型 ID 与 AppKey 不匹配而被排除，使用实测成功的
`DeepSeek-V3-0324` 代替。

## 验证边界

- 验证使用国内站、海外站各自签发的测试凭据；凭据不写入本报告、源码或
  `.difypkg`。
- 模型目录、最小请求和多模态能力分别验证，不能用 `/models` 的存在性代替
  实际调用验证。
- 发布包只暴露 `provider/moyu.yaml` 显式列出的模型，未注册 YAML 不会出现在
  Dify 的该供应商模型列表中。
