## Function Calling 验收

1. 在 Agent 节点选择 Function Calling / FunctionCalling 策略。
2. 选择一个具有双站流式证据的模型，例如 `qwen3.6-plus`。
3. 挂接本地确定性加法工具 `add(a, b)`；不要使用天气、搜索或其他外部服务。
4. 输入要求模型通过工具计算 `2 + 3` 的提示。
5. 从运行日志分别确认：模型产生结构化工具请求、工具真实执行、结果以相同
   `tool_call_id` 回传、模型收到工具结果并给出最终响应。只看到答案 `5` 不算通过。
6. 国内凭据、海外凭据分别运行一次，并记录模型 ID、策略、节点日志及最终结果。
7. 使用同一模型补一次无工具普通聊天回归。

  `kimi-k2.7-code` 只有 `tool-call`，不得出现 `stream-tool-call`。
- 台账中的 7 个未通过双站准入模型不得出现工具标签。
- 10 个仅国内模型虽然已有国内正向证据，但 0.0.8 公共 YAML 不开放工具标签。
- 任何模型都不得出现 `multi-tool-call`。

完整精确清单与证据引用见 `docs/VERIFIED_TOOL_CAPABILITIES.yaml`。
